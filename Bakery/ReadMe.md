## 📄 Sections

- **Navbar** — Responsive with CSS-only burger menu
- **Hero** — Full screen background with overlay
- **Who We Are** — Two column grid layout
- **Our Location** — Reversed two column grid layout
- **Our Baking** — Three column product cards
- **Contact** — Contact info with embedded Google Map
- **Footer** — Four column grid with social links

## 💡 What I Learned

- CSS Variables — Primitive & Semantic tokens
- BEM Naming Convention
- Mobile First approach
- CSS Grid & Flexbox
- Semantic HTML elements
- CSS-only Burger Menu using `:checked` selector
- `clamp()` for responsive typography
- `aria-label` for accessibility
- `object-fit` for images
- `linear-gradient` overlay technique
